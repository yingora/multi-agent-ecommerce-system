# Upstream license statement and uncertainty

## Verified evidence

The README at upstream commit `faf0fd8309c550426f3b2cce057dd4566e209e09` contains an MIT badge and an explicit license section. Its statement is:

> [MIT License] — 随意使用、修改、商用，保留 License 声明即可。

The bracketed label links to a file named `LICENSE` in the upstream README. The sentence permits use, modification and commercial use while preserving the license notice. This is evidence of stated permission beyond a badge.

Source: [upstream README at the audited commit](https://github.com/bcefghj/multi-agent-ecommerce-system/blob/faf0fd8309c550426f3b2cce057dd4566e209e09/README.md). Verification used the README stored in the local Git object at that exact commit. The commit's complete tracked tree contains no formal LICENSE, COPYING or NOTICE file. No full MIT text or separate copyright notice was found in the baseline review. A fresh web fetch of the commit page was unavailable during release preparation; no assertion is made about later upstream changes.

## What this release does

- Preserves attribution, the exact baseline commit and this permission statement.
- Documents that the full intended terms, copyright notice and redistribution scope remain incompletely documented.
- Adds no LICENSE file, invented upstream copyright statement, replacement license or MIT badge implying a complete verified notice.
- Prepares the local public-file package without waiting for an issue response. No issue has been posted and no repository has been created or uploaded as part of this preparation.

The README statement expresses MIT intent and broad permission. The missing formal notice still creates uncertainty; this package does not certify legal clearance or conclude that the README permission is meaningless. Public-file preparation is distinct from resolving that uncertainty. Obtaining a complete notice or explicit confirmation from the rights holder remains recommended. Attribution by itself does not resolve missing license terms, and dependency licenses must be considered separately.
